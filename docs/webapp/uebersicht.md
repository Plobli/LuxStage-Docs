# Übersicht & Konzept

LuxStage ist eine webbasierte Bühnen-Beleuchtungsmanagement-App für Theatertechniker und Lichtdesigner. Sie ermöglicht das Verwalten von **Shows** (Produktionen), das Dokumentieren von **Lichtstellen (Kanäle)**, das Erstellen von **Grundrissplänen** sowie das Hinterlegen von **technischen Notizen**.

## Kernfunktionen

- Übersichtliche Kanalplan-Verwaltung pro Show (Kanal-Nummer, Farbe, Gerät, Notizen)
- Interaktiver grafischer Grundrisseditor
- Textuelle Info-Abschnitte (Rigging, Cue Notes, benutzerdefinierte Felder)
- Foto-Dokumentation
- Import (EOS-Pult, CSV) & Export (PDF, CSV)
- Versionsverlauf
- Archivierung abgeschlossener Shows
- Spielort-Vorlagen für wiederkehrende Produktionsorte
- Mehrbenutzer-Verwaltung mit Rollen

## Navigation

Die vertikale **Seitenleiste** links enthält vier Symbole:

| Symbol | Bereich | Beschreibung |
|--------|---------|--------------|
| **Shows** | Startseite – alle aktiven Shows |
| **Archiv** | Archivierte Shows |
| **Vorlagen** | Spielort-Vorlagen verwalten |
| **Einstellungen** | App-Einstellungen |

Ganz unten befindet sich der **Abmelden**-Button (Pfeil-Symbol).
