# Shows

## Shows-Übersicht

Die Startseite zeigt alle vorhandenen Shows als Karten. Jede Karte enthält:

- **Kürzel** – Erste Buchstaben des Shownamens (farbiger Kreis), z. B. „H" für Hamlet
- **Showname** – z. B. „Hamlet"
- **Datum** – Vorstellungsdatum, z. B. „2026-04-30"
- **Letzter Bearbeiter** – E-Mail-Adresse und Zeitstempel der letzten Änderung
- **Archivieren-Button** – Ablagekorb-Symbol (⊟) rechts auf der Karte

Shows werden in zwei Gruppen angezeigt:

1. **Ohne Spielort** – Shows ohne zugewiesenen Spielort erscheinen in einem anonymen Bereich (durch einen Trennstrich „—" gekennzeichnet)
2. **Mit Spielort** – Shows werden unter dem jeweiligen Spielort-Namen als Überschrift gruppiert (z. B. „Venue 1")

## Neue Show erstellen

1. Klick auf **„Neue Show"** (oben rechts)
2. Im Dialog die Felder ausfüllen:

| Feld | Beschreibung |
|------|-------------|
| **Name** | Titel der Produktion (z. B. „Hamlet") |
| **Datum** | Vorstellungsdatum (Standard: heutiges Datum) |
| **Spielort** | Spielort-Vorlage auswählen oder „Kein Spielort" lassen |

3. Klick auf **„Show erstellen"**

::: tip Hinweis
Wird ein Spielort ausgewählt, übernimmt die neue Show automatisch das Kanaltemplate, die Sections und den Grundriss des gewählten Spielorts.
:::

## Show öffnen

Einfach auf die gewünschte Show-Karte klicken. Die Show öffnet sich im **Kanäle**-Tab.

## Show archivieren

Klick auf das **Archivieren-Symbol** (⊟) auf der Show-Karte. Die Show verschwindet von der Startseite und erscheint im **Archiv**.

::: warning Achtung
Das Archivieren kann im Archiv rückgängig gemacht werden. Eine endgültige Löschung ist über den Archiv-Bereich möglich.
:::
