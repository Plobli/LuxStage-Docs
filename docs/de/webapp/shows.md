# Shows

## Shows-Übersicht

Die Startseite zeigt alle vorhandenen Shows als sortierbare Liste. Jede Zeile enthält:

- **Name** – Showname, darunter ggf. der Untertitel, z. B. „Hamlet"
- **Stand** – Vorstellungsdatum, z. B. „30.04.2026"
- **Spielzeit** – z. B. „25/26" (ab Bildschirmbreite lg sichtbar)
- **Bearbeitung** – E-Mail-Adresse der letzten bearbeitenden Person
- **Archivieren-Button** – erscheint beim Überfahren der Zeile rechts

Über den Spaltenüberschriften (Name, Stand, Spielzeit, Bearbeitung) lässt sich die Liste sortieren.

Shows werden nach Spielort gruppiert angezeigt, mit dem Spielort-Namen als Überschrift. Shows ohne zugewiesenen Spielort erscheinen unter „—".

## Neue Show erstellen

1. Klick auf **„Neue Show"** (Button unten rechts)
2. Im Dialog die Felder ausfüllen:

| Feld | Beschreibung |
|------|-------------|
| **Name** | Titel der Produktion (z. B. „Hamlet") |
| **Datum** | Vorstellungsdatum (Standard: heutiges Datum) |
| **Untertitel** | Optionaler Zusatztext |
| **Spielzeit** | Optional, z. B. „25/26" |
| **Spielort** | Spielort-Vorlage auswählen oder „Kein Spielort" lassen |
| **Aufbau-Bereiche** | Beleuchtungsgestelle und/oder Zugstangen aktivieren |

3. Klick auf **„Show erstellen"**

::: tip Hinweis
Wird ein Spielort ausgewählt, übernimmt die neue Show automatisch das Kanaltemplate, die Sections und den Grundriss des gewählten Spielorts.
:::

## Show öffnen

Einfach auf die gewünschte Show-Zeile klicken. Die Show öffnet sich im **Kanäle**-Tab.

## Show archivieren

Beim Überfahren der Show-Zeile erscheint rechts ein **Archivieren-Symbol**. Nach Bestätigung verschwindet die Show von der Startseite und erscheint im **Archiv**.

::: warning Achtung
Das Archivieren kann im Archiv rückgängig gemacht werden. Eine endgültige Löschung ist über den Archiv-Bereich möglich.
:::
