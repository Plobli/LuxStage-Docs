# Features

Everything you need on stage.

## Channel Lists

### The channel plan that is current on all devices

All fixture channels, DMX addresses, fixture types, positions, gel filters and notes per show in one place — structured, searchable and always up to date.

**Overview & quick search**
All channels in a table — grouped by position. Real-time filtering by channel number, fixture type, position or notes.

**Duplicate warning**
Automatic notification for duplicate DMX addresses or channel numbers.

**Auto-save**
Changes are automatically saved and synchronised to all connected devices. No manual saving needed.

**Gel filter management**
Store colour codes (Rosco, Lee) directly in the channel and display them visually.

---

## Focusing & OSC

### Direct connection to the console

The focusing mode of the iOS app combines checklist and console control. One tap switches the channel on, a second tap switches it off — no flipping through printed documents, no searching.

**Focus mode**
- Channels grouped by position — same view as in the channel plan
- Check off focused fixtures with a checkmark
- Search by channel or position during focusing
- Reference photos directly at the channel — no searching in the gallery

**OSC control (ETC EOS)**
Control the console directly from the app.

| Function | Description |
|----------|-------------|
| Focus mode | One tap = Full, second tap = Out |
| OSC numpad | Free command input: channel and group numbers, moving light control |
| Configuration | Configurable per venue: IP address, OSC port, EOS user ID |

## Setup Notes

### Everything important in writing — and always current

Cable routes, positions, agreements with the director, special features of the venue — setup notes are attached to each show and synchronised in real time.

**Rich-text editor**
WYSIWYG editor with formatting options — bold, italic, heading, bullet list, numbered list, and tables.

**Structured fields**
In addition to free text: self-definable fields per section for height specifications or positions with measurements, including an optional unit.

**Freely addable sections**
Each venue template brings its own default sections — "Setup", "Notes" and more. You can also add your own sections (text or fields) per show.

**Live synchronisation**
Multiple users can edit simultaneously. Changes appear in real time.

---

## Photo Documentation

### Pictures say more than a written plan

Setup situations, rigging details, cable routing — all photographed directly in the app, labelled and assigned to a channel. Ready to hand at the next setup.

**In-app camera (iOS)**
Take photos directly from the app. Automatically linked to the show and saved on the server.

**Drag & drop upload (web)**
Drag multiple photos into the browser at once.

**Lightbox & gallery**
Full-screen view with navigation, grid overview of all production photos, drag & drop for sorting.

**Channel assignment**
Assign a photo to a specific channel — during focusing, the reference photo is displayed directly at the channel. Visual context at the touch of a button.

**PDF export**
All production photos are embedded in the PDF report — complete documentation in one file.

---

## Import & Export

**EOS import**
Import CSV exports directly from ETC EOS consoles. Active channels are automatically recognised and imported. You only need to add your notes.

**CSV import**
Upload semicolon-separated channel lists directly — e.g. from Excel or other systems.

**PDF export**
Generate a complete, print-ready report with one click. The PDF contains:

| Section | Content |
|---------|---------|
| Title page | Production name, date, venue |
| Channel list | Sorted by position & channel, with DMX, fixture, gel, notes |
| Setup notes | All sections incl. structured fields |
| Floor plan | Stage floor plan, if present |
| Photo gallery | All production photos embedded |

## Collaboration

### Everyone sees the same thing — in real time

Lighting technicians, assistants and stage managers can work simultaneously without overwriting each other. Changes appear immediately on all connected devices.

**Presence awareness**
See at a glance who is currently working on the same production — whether in the web app or in the iOS app. Online status in real time.

**iOS + web simultaneously**
One user edits on a laptop, another checks on an iPhone — both see the same state. No conflicts, no manual reconciliation.

---

## Venue Templates

### Create once, use always

Save venues with a fixed channel structure as a template — apply it to each new production with a click. Channel lists, note sections and structured fields are inherited and can be customised per show.

**Template contains:**
- **Channel list** — fixtures, DMX addresses, fixture types and positions of the venue
- **Note sections** — "Setup", "Notes" and any number of custom sections
- **Structured fields** — measurements, positions
- **Floor plan** – stage floor plan

---

## Data Protection

### No change is lost

Automatic version history, complete backups and restoration at the push of a button — for emergencies, and simply for peace of mind.

**Automatic version history**
A snapshot of the show state is saved every 10 minutes. Timeline with date, time and user info — restore any earlier state.

**Complete backup**
Download all data — database and photos — as a ZIP file. Timestamp automatically included in the filename. For external archiving or before major changes.

**Restore**
Restore from an earlier ZIP file — with validation before applying. Complete rollback possible.
