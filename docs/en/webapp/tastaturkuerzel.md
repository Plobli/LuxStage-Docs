# Keyboard Shortcuts

Overview of all web app keyboard shortcuts in one place.

## General

| Action | Shortcut |
|--------|----------|
| Undo | ⌘Z (Mac) / Ctrl+Z (Win) |
| Redo | ⌘⇧Z (Mac) / Ctrl+Y (Win) |

## Floor plan editor

### Tools

| Tool | Shortcut |
|------|----------|
| Select | V |
| Pan | H |
| Draw line | L |
| Draw rectangle | R |
| Draw ellipse/circle | E |
| Add text | T |
| Place channel | C |

### Actions

| Action | Shortcut |
|--------|----------|
| Undo | Ctrl+Z |
| Redo | Ctrl+Y / Ctrl+Shift+Z |
| Delete selection | Delete / Backspace |
| Reset view | F / Ctrl+0 |
| Temporarily pan view | Hold spacebar |
| Move selection | Arrow keys (10 units with Shift) |
| Copy / Paste | Ctrl+C / Ctrl+V |
| Duplicate | Ctrl+D |
| Select all | Ctrl+A |
| Cancel tool / clear selection | Esc |
| Show/hide grid | G |
