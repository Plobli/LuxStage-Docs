# Photos

The **Photos** tab is used for visual documentation of the show – e.g. photos of the stage setup, special effects, rehearsals or the finished lighting.

## Add a photo

1. Click **"+ Add photo"**
2. Select an image file from the file system and confirm
3. The photo appears in the gallery

If no photos are present yet, the message **"No photos yet."** is displayed.

## View photos

All uploaded photos are displayed as a gallery grid. The number of photos is shown in the top right.

Each photo has two fields:

- **Description** – Free text for documentation, e.g. position, fixture or note
- **Channel** – Comma-separated channel numbers assigned to the photo (e.g. `651, 652, 653, 654`). These photos are then assigned to the corresponding channels in the iOS app and can be accessed during focusing.

## Print photos

Under **Settings → Account → Photos per print page** you can specify how many photos fit on an A4 page when printing (default: 4).

::: tip Tip
The PDF export (via **Export → PDF**) also includes the photos from the Photos tab, if present.
:::
