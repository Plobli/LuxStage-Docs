# Version History

LuxStage automatically saves a **version history** of all changes to a show. This allows earlier states to be restored.

## Open version history

Click the **"History"** button in the top menu bar of a show. A side panel opens on the right.

## View versions

The panel shows a list of all saved versions with **date and time**, e.g.:

- 30.4.2026, 17:37:15
- 30.4.2026, 15:01:47
- 30.4.2026, 14:48:31
- 30.4.2026, 14:45:23

## Restore a version

Click on a version entry → the state of the show at that point in time is restored.

::: warning Note
Restoring an old version overwrites the current state. Make sure you have backed up the current state first if needed.
:::

## Close the panel

Click the **×** icon in the top right of the history panel.
