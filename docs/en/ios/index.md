# iOS App – Overview

The native LuxStage app for iPhone and iPad is written in SwiftUI and optimised for touch — whether at the mixing desk or on stage.

## App structure

The app is organised in two levels:

**Global tabs** (visible on the shows overview):

| Tab | Function |
|-----|----------|
| **Shows** | List of all shows, grouped by venue |
| **OSC** | Direct EOS control without an active show |
| **Settings** | Server URL, language, OSC venues |

**Show tabs** (visible within an open show):

| Tab | Function |
|-----|----------|
| **Setup** | Setup checklist and show details |
| **Focus** | Channel plan for focusing fixtures |
| **OSC** | EOS remote control (numpad, playback, fader, ML) |
| **More** | Photos and floor plan |
